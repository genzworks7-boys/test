Frequently Asked Questions

Everything you need to know about this registration portal and Google Sheets integration.

We use Google Apps Script deployed as a Web App (/exec endpoint). The client browser posts a lightweight JSON payload. Google Apps Script executes with the spreadsheet owner's authorization and appends the new record securely using SpreadsheetApp, requiring zero API subscriptions or paid gateways.
Google Apps Script does not respond to HTTP OPTIONS preflight requests. Sending a standard application/json header triggers preflight, which causes modern browsers to abort. We send the payload with Content-Type: text/plain;charset=utf-8 (which bypasses preflight). Google Apps Script processes the body and returns a 302 redirect to an echo endpoint containing Access-Control-Allow-Origin: *, allowing the browser to parse the verified confirmation response cleanly.
In spreadsheet software (Google Sheets, Excel), entering values starting with characters like =, +, -, or @ can trigger formula execution (such as =IMAGE() or external data exfiltration via =IMPORTXML()). Our backend sanitizes all inputs by prefixing trigger characters with a single apostrophe ('), forcing Google Sheets to treat the data as literal text.
The honeypot is a hidden input field (named website) invisible to human visitors. Automated web scrapers and generic spam bots frequently fill in every input field they encounter. If this field contains any text upon submission, both the frontend and Google Apps Script immediately discard the submission. However, a honeypot alone does not stop sophisticated human-assisted bots or targeted spam; for high-traffic public campaigns, adding Google reCAPTCHA or Cloudflare Turnstile provides supplementary defense.

Integration & API Configuration

How to connect your Google Sheet:
  1. Open your Google Sheet and select Extensions > Apps Script.
  2. Paste the code from google-apps-script/Code.gs.
  3. Click Deploy > New deployment > Web app.
  4. Set Execute as: Me and Who has access: Anyone.
  5. Copy the resulting Web App URL ending in /exec and paste below.
